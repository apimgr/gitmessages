# Git Messages

Git Messages is a full-stack reference for Conventional Commits and Angular commit message conventions. The embedded catalog describes the supported commit types, emoji, examples, and templates. The browser builder and companion CLI validate and format commit messages.

## Product boundaries

The catalog is curated and embedded into each release. The service has no user accounts, submitted catalog content, or paid tiers. Anonymous owner tokens support protected API capabilities, and configured contact/security forms support reports required by the shared server specification. It does not query third-party content or data providers; a dedicated Tor process and optional I2P provider supply alternate access to the same local service. Changes to the catalog ship through application releases.
