# Git Messages

Git Messages is a full-stack reference for Conventional Commits and Angular commit message conventions. The embedded catalog describes the supported commit types, emoji, examples, and templates. The browser builder and companion CLI validate and format commit messages.

## Product boundaries

The catalog is curated and embedded into each release. The service has no user accounts, submissions, paid tiers, API keys, database, or runtime external-service calls. Changes to the catalog ship through application releases.
