# Git Messages

Git Messages is a full-stack reference for Conventional Commits and Angular commit message conventions. The embedded catalog describes the supported commit types, emoji, examples, and templates. The browser builder and companion CLI validate and format commit messages.

## Product boundaries

The catalog is curated and embedded into each release. The service has no user accounts, submitted catalog content, or paid tiers. Anonymous owner tokens support protected API capabilities, and configured contact/security forms support reports required by the shared server specification. It does not query third-party content providers for catalog or message data. AI.md-required security and GeoIP feeds supply operational security datasets only; Tor and optional I2P provide alternate access to the same local service. Changes to the catalog ship through application releases.
